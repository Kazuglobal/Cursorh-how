## 1. Manus AI とは何か

### 概要

Manus AI は、中国のスタートアップ **Monica.im（旧 Butterfly Effect）** が開発した**汎用AIエージェント**である。2025年3月に公開され、「世界初の汎用AIエージェント」を標榜して大きな話題を呼んだ。

### 開発元

| 項目 | 詳細 |
|------|------|
| 開発会社 | Monica.im（Monica AI） |
| 所在地 | 中国・深セン |
| 創業者 | Yichao 'Peak' Ji（季逸超） |
| 背景 | ブラウザ拡張AI「Monica」の開発元として知られる |
| 主要投資家 | Benchmark、Tencent 等 |

### 位置づけ

Manus AI は単なるチャットボットではなく、**自律的にタスクを計画・実行するAIエージェント**という点で、ChatGPT や Claude とは異なるカテゴリに位置する。ユーザーの指示を受けて、複数のツール（ブラウザ、コードエディタ、ファイルシステム等）を自律的に操作してタスクを完了する。

### GAIA ベンチマーク

Manus AI は公開時に **GAIA（General AI Assistants）ベンチマーク** で当時の最高スコアを記録したと発表し、注目を集めた。ただし、このベンチマーク結果については第三者による独立検証が十分に行われていないとの指摘もある。

## 2. アクセス方法

### アカウント作成

1. **公式サイト**: https://manus.im にアクセス
2. **サインアップ**: メールアドレスまたは Google アカウントで登録
3. **ウェイトリスト**: 初期は招待制（ウェイトリスト方式）であったが、2025年前半に段階的に一般開放された

### 利用環境

| 環境 | 対応状況 |
|------|----------|
| Webブラウザ | 対応（主要なアクセス方法） |
| デスクトップアプリ | 2025年前半時点では未提供（Web版のみ） |
| モバイル | Webブラウザ経由でアクセス可能 |
| API | 一般公開APIは2025年前半時点では未提供 |

### 招待制の経緯

- **2025年3月**: 招待コード制でローンチ。招待コードは既存ユーザーから取得する必要があった
- **2025年3月〜4月**: 大量のウェイトリスト登録が発生（数十万人規模と報道）
- **2025年4月以降**: 段階的にアクセスを拡大。無料トライアルクレジットの付与で新規ユーザーを受け入れ

## 3. 主要機能

### 3.1 自律エージェント（Autonomous Agent）

Manus AI の最大の特徴は**タスクの自律実行**である。

- ユーザーが自然言語でタスクを記述すると、Manus が自動的にサブタスクに分解
- 各ステップを順次実行し、中間結果を確認しながら進行
- **ToDoリスト形式**で進捗を可視化
- エラーが発生した場合は自動でリトライや代替手段を試行

### 3.2 ブラウザ制御（Web Browsing）

仮想ブラウザをリアルタイムで操作する能力を持つ。

- Webサイトの閲覧・情報収集
- フォームの入力・送信
- 複数ページにまたがる情報の統合
- スクリーンショットの取得と解析
- ログインが不要な公開サイトでの操作

**特徴**: ユーザーはブラウザ操作の様子をリアルタイムで観察できる

### 3.3 コード生成・実行（Code Generation & Execution）

サンドボックス環境内でコードを生成・実行する。

- **対応言語**: Python、JavaScript/TypeScript、HTML/CSS、Shell Script 等
- **実行環境**: クラウド上のサンドボックス（隔離された仮想環境）
- データ分析スクリプトの作成と実行
- Webアプリケーションのプロトタイプ生成
- CSVやJSONデータの処理

### 3.4 ファイル操作

- ファイルのアップロード・ダウンロード
- ドキュメント（PDF、Word、Excel 等）の読み取りと生成
- 画像の処理・変換
- データファイルの分析と可視化

### 3.5 マルチステップ計画（Multi-Step Planning）

複雑なタスクに対する段階的な実行計画の策定と実行。

```
ユーザーの指示例:
「東京の人気カフェ10店舗を調査し、
 住所・営業時間・評価をExcelにまとめて」

Manusの実行計画:
1. Google で「東京 人気カフェ ランキング」を検索
2. 上位の情報源から10店舗を特定
3. 各店舗の詳細情報を個別に収集
4. 情報をExcel形式に整理
5. ファイルを生成してダウンロードリンクを提供
```

### 3.6 サンドボックス環境

- 各タスクは**隔離されたクラウドサンドボックス**内で実行
- ユーザーのローカル環境には影響しない
- Linuxベースの仮想環境（Ubuntu）
- 一定時間後にサンドボックスは自動で破棄される
- pip/npm 等でのパッケージインストールが可能

### 3.7 マルチモーダル対応

- 画像の認識と解析
- 画像内のテキスト抽出（OCR）
- グラフ・チャートの生成
- スクリーンショットを用いたUI解析

## 5. 料金体系

> 注意: 料金は頻繁に変更される可能性があるため、最新情報は公式サイトで確認してください

### 2025年前半時点の料金構成

Manus AI は**クレジットベース**の料金体系を採用している。

| プラン | クレジット | 料金（目安） | 備考 |
|--------|-----------|-------------|------|
| Free | 初回のみ少量付与 | 無料 | 新規登録時に試用クレジット付与 |
| Plus | 月間一定量 | $39/月 程度 | 個人利用向け |
| Pro / Team | 大量クレジット | 未公開 / 要問合せ | ビジネス利用向け |

### クレジットの仕組み

- **1タスク = 数クレジット〜数十クレジット**を消費
- タスクの複雑さ（ステップ数、ブラウジング回数、コード実行回数）に応じて変動
- 簡単な質問: 1〜2クレジット
- 複雑なリサーチ + レポート作成: 10〜30クレジット以上
- クレジットは月次でリセット（未使用分は繰り越し不可の場合あり）

### 無料枠の注意点

- 初回登録時に少量の無料クレジットが付与される
- 無料クレジットでは数回のタスク実行が可能
- 継続利用には有料プランへの加入が必要

## 6. 制限事項

### 6.1 できること

- 公開Webサイトの閲覧と情報収集
- サンドボックス内でのコード実行
- ファイルの生成とダウンロード
- 複数ステップにわたる自律的タスク実行
- データ分析と可視化
- ドキュメント生成

### 6.2 できないこと / 制限

| 制限 | 詳細 |
|------|------|
| ローカル環境へのアクセス | ユーザーのPCのファイルを直接操作できない |
| 認証が必要なサービス | ログインが必要なサイトへの自動アクセスは制限あり |
| リアルタイム連続監視 | 長時間の監視タスクには非対応 |
| 大規模コードベース | プロダクションレベルの大規模開発には不向き |
| ハードウェア操作 | 物理デバイスの制御は不可 |
| 金銭取引 | 購入・決済等の金銭に関わる操作は不可 |
| 長時間タスク | サンドボックスにはタイムアウトがある（数十分程度） |
| GPUアクセス | 機械学習モデルのトレーニング等は制限あり |

### 6.3 セキュリティに関する考慮事項

- **サンドボックス隔離**: タスクはクラウド上の隔離環境で実行される
- **データの取り扱い**: アップロードしたファイルやタスク履歴はサーバーに保存される可能性がある
- **機密情報**: 個人情報や企業秘密をアップロードする際は注意が必要
- **中国企業**: 開発元が中国企業であることから、データの保管場所やプライバシーポリシーについて慎重に確認すべき
- **APIキー等**: Manus にAPIキーやパスワード等の秘密情報を渡すことは推奨されない

## 7. 初心者向けガイド

### 7.1 はじめの一歩

1. https://manus.im にアクセスしてアカウントを作成
2. 無料クレジットを確認
3. 簡単なタスクから試す（例:「Pythonで九九の表を作って」）
4. 実行過程をリアルタイムで観察して動作を理解する

### 7.2 効果的なタスク指示の書き方

#### 良い指示の例

```
具体的で、ゴールが明確な指示:

「東京都内のコワーキングスペース10箇所を調査し、
以下の項目を含むExcelファイルを作成してください:
- 名称
- 所在地（最寄り駅）
- 月額料金
- 営業時間
- WiFi速度（情報があれば）
料金の安い順にソートしてください。」
```

#### 悪い指示の例

```
曖昧で、ゴールが不明確な指示:

「コワーキングスペースについて調べて」
→ 何をどこまで、どの形式で求めているか不明
```

### 7.3 タスク指示のコツ

| コツ | 説明 | 例 |
|------|------|-----|
| 具体的なゴールを書く | 最終成果物を明示 | 「Excelファイルで」「PDFレポートで」 |
| 項目を列挙する | 必要な情報を箇条書き | 「名前、価格、URL」 |
| 形式を指定する | 出力形式を明記 | 「表形式で」「グラフ付きで」 |
| 範囲を絞る | スコープを限定 | 「東京都内」「2024年以降」 |
| ステップを示す | 大まかな手順を提示 | 「まず検索し、次に比較し...」 |

### 7.4 よくある失敗と対策

| 失敗 | 原因 | 対策 |
|------|------|------|
| 情報が古い | Webの情報が更新されていない | 「最新の情報を確認して」と追記 |
| タスクが途中で止まる | 複雑すぎる指示 | タスクを分割して依頼 |
| 期待と異なる出力 | 指示が曖昧 | 出力形式・項目を具体的に指定 |
| クレジット消費が多い | 不必要に複雑なタスク | シンプルなタスクに分割 |

## 8. Cursor / Claude Code との比較・使い分け

### 8.1 3ツールの特性比較

| 項目 | Manus AI | Cursor | Claude Code |
|------|----------|--------|-------------|
| **カテゴリ** | 汎用AIエージェント | AIコードエディタ | CLIコーディングツール |
| **得意領域** | リサーチ、データ分析、自動化 | コード編集、リファクタリング | ターミナル操作、コード生成 |
| **実行環境** | クラウドサンドボックス | ローカル（VS Code fork） | ローカルターミナル |
| **ブラウザ操作** | 可能（仮想ブラウザ） | 不可（MCP経由で一部可能） | 不可（MCP経由で一部可能） |
| **ファイル操作** | サンドボックス内のみ | ローカルファイル直接 | ローカルファイル直接 |
| **Git統合** | 限定的 | 完全統合 | 完全統合 |
| **大規模コードベース** | 不向き | 得意 | 得意 |
| **非コードタスク** | 得意 | 限定的 | 限定的 |
| **料金** | $39/月〜 | $20/月〜 | API従量課金 |
| **オフライン** | 不可 | 一部可能 | 一部可能 |

### 8.2 使い分けガイド

#### Manus AI を使うべき場面

- Web上の情報を収集してレポートにまとめたい
- データ分析の結果をExcel/PDFで出力したい
- プログラミング知識がなくてもタスクを自動化したい
- 複数サイトを横断的に調査したい
- プロトタイプを素早く作りたい（コードの品質より速度重視）

#### Cursor を使うべき場面

- 既存のコードベースを編集・リファクタリングしたい
- リアルタイムでコード補完を受けながら開発したい
- プロジェクト全体を理解した上でのコード変更が必要
- デバッグ作業（ブレークポイント、ステップ実行との連携）
- チーム開発でのコード品質維持

#### Claude Code を使うべき場面

- ターミナル中心のワークフローで開発したい
- Git操作、テスト実行、ビルドを含む包括的な開発タスク
- 複数ファイルにまたがる大規模なコード変更
- CI/CDパイプラインの構築・デバッグ
- エディタに依存しない柔軟な開発

### 8.3 組み合わせ活用例

```
例: 新サービスの立ち上げ

1. Manus AI: 市場調査・競合分析レポートを作成
2. Manus AI: プロトタイプ（HTML/CSS/JS）を生成
3. Cursor: プロトタイプを本格的なNext.jsプロジェクトに変換
4. Claude Code: テスト作成、CI/CD設定、デプロイ自動化
5. Manus AI: ユーザーフィードバック収集・分析
```

### 8.4 判断フローチャート

```
タスクの種類は？
├── コーディング中心
│   ├── 既存プロジェクトの編集 → Cursor
│   ├── 新規プロジェクト構築 → Claude Code or Cursor
│   └── 簡単なプロトタイプ → Manus AI
├── リサーチ・調査
│   └── Web情報収集 + レポート → Manus AI
├── データ分析
│   ├── ローカルデータ + コード → Claude Code
│   └── Web収集 + 分析 + レポート → Manus AI
└── ドキュメント作成
    ├── 技術ドキュメント → Claude Code or Cursor
    └── 調査レポート → Manus AI
```

## 9. まとめ

### Manus AI の強み

- **非エンジニアでも使える**: 自然言語だけで複雑なタスクを自動実行
- **ブラウザ操作**: Web上の情報収集を自動化できる唯一のツール（3ツール比較の中で）
- **エンドツーエンドの自動化**: 調査からレポート生成まで一気通貫
- **視覚的な実行過程**: タスクの進行をリアルタイムで観察可能

### Manus AI の弱み

- **本格的な開発には不向き**: サンドボックスの制約がある
- **料金がやや高い**: 複雑なタスクではクレジット消費が大きい
- **セキュリティ懸念**: 中国企業運営のため、機密データの取り扱いに注意
- **安定性**: サービス初期のため、不安定な場合がある
- **ローカル連携なし**: ユーザーのPC環境と直接連携できない

### 推奨される使い方

1. **まずは無料クレジットで試す**: 簡単なリサーチタスクで体験
2. **Cursor / Claude Code と併用**: 開発は専用ツール、調査・分析はManus
3. **機密データは避ける**: 公開情報の処理に限定して利用
4. **タスクは具体的に記述**: 曖昧な指示はクレジットの無駄遣いにつながる
